# test-3-1
코디세이 기타미션

## 별따기 셈놀이

초등학생을 위한 사칙연산 퀴즈 웹앱입니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

- 더하기 · 빼기 · 곱하기 · 나누기 중 하나와 쉬움 · 보통 · 어려움 중 한 단계를 골라 10문제를 풉니다.
- 푸는 동안 위쪽에 걸린 시간과 목표 시간이 보입니다.
- 다 풀면 점수(1문제 10점), 걸린 시간, 문제별 정답을 보여 줍니다.
- 별: 10개 맞히면 3개, 8~9개 2개, 5~7개 1개.
- 7문제 이상 맞히고 목표 시간(쉬움 1분, 보통 1분 30초, 어려움 2분 30초) 안에 끝내면 분홍 보너스 별 1개와 시간 보너스 점수(최대 50점)를 더 받습니다.
- 나눗셈은 나머지 없이 나누어떨어지는 문제만 나옵니다.
- 단계별 최고 기록은 그 기기의 브라우저에 저장됩니다.
